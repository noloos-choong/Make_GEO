# GEO (Generative Engine Optimization) 개요

## GEO란?

Generative Engine Optimization(GEO)은 ChatGPT, Perplexity, Google SGE 같은
AI 기반 검색엔진에서 콘텐츠가 인용·노출되도록 최적화하는 기법입니다.
기존 SEO가 검색 결과 순위를 높이는 것이라면, GEO는 AI 답변에 내 콘텐츠가
포함되도록 만드는 것이 목표입니다.

## GEO 핵심 요소

| 요소 | 설명 |
|------|------|
| 인용 가능성 | AI가 답변에 직접 인용할 수 있는 명확한 문장 구조 |
| 구조화 데이터 | JSON-LD, FAQ 스키마 등 AI가 파싱하기 쉬운 형식 |
| 권위성 | 출처 명시, 전문성 있는 정보 제공 |
| 질의 매칭 | 사용자 자연어 질의와 일치하는 콘텐츠 구성 |
| 신선도 | 최신 정보 유지 및 업데이트 주기 |

## 개발 방향

1. **화면(Screens)**: 사용자가 GEO 분석·최적화 작업을 직관적으로 수행할 수 있는 UI
2. **동작(Actions)**: AI 엔진 연동, 점수 계산, 콘텐츠 최적화 로직
